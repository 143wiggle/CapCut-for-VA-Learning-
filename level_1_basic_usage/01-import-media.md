Level 1 — Basic Usage
Task 1: Import Media
Goal

Learn how to import videos, photos, and audio into CapCut — the foundational step before any editing. This teaches you how to set up your workspace and bring in raw content from clients.

Steps to Practice

Open CapCut (desktop or mobile).

Create a new project by clicking New Project.

Click Import or + Add depending on your app version.

Choose one video, one image, and one audio file from your device.

Drag the imported media into the Timeline.

Arrange the video, image, and audio in the order you prefer.

Play the timeline to confirm everything is loaded correctly.

Practice Example

Media to Import:

Project Activity:

Add the video first

Place the image above it (overlay)

Add the audio under the video track

This demonstrates that you can import multiple media types and understand how each one appears in the timeline.
